# План и факты

## Что известно об Antigravity 2.26 (из встроенного skill `agy-customizations`)

Источник: `~/.gemini/antigravity/builtin/skills/agy-customizations/` на машине владельца.

- **Плагин** — папка `plugins/<имя>/` с `plugin.json` (обязателен), опционально `skills/`, `rules/` (рекомендован один `rules/AGENTS.md`), `mcp_config.json`, `hooks.json` (строго в корне плагина). Глобальный корень — `~/.gemini/config/`, проектный — `.agents/` в репозитории.
- Плагины включены по умолчанию; `"disabled": true` в `plugin.json` выключает. Выбор пользователя хранится в `~/.gemini/config/config.json` → `plugins.<папка>.enabled` и важнее `plugin.json`.
- **Workflows устарели**, вместо них skills: `skills/<имя>/SKILL.md` с frontmatter `name` и `description`. Skill вызывается `/<имя>` и может быть выбран агентом сам.
- **Бюджет контекста:** always-on и глобальные правила делят 20 000 токенов; файл правила — до 24 000 байт. Лишние правила понижаются до ссылки на файл. Skills загружаются постепенно: в контексте только имя и описание, тело — при вызове. Поэтому объёмные инструкции оформляем skills, а правила держим короткими.
- **MCP:** `mcp_config.json` → `mcpServers`; stdio (`command`, `args`, `env`) или Streamable HTTP (`url`). Legacy SSE не поддерживается.
- Размер окна контекста модели задаёт сервер — увеличить его клиентом нельзя. Помогают: `/handoff` + `/resume`, короткие правила, skills вместо длинных правил, `AGENTS.md` в проекте.

## Этапы

1. **Плагин (готов черновик):** skills `handoff`, `resume`, `review`, `commit`, `fix`, `explain`; пресеты правил в `presets/rules/`.
2. **Проверка владельцем:** скопировать плагин вручную, проверить, что команды видны в чате и работают на русском.
3. **Установщик EXE:** окно с галочками (команды, пресеты правил, MCP), сборка `rules/AGENTS.md` из выбранных пресетов, маркер владения, удаление.
4. **MCP:** список проверенных серверов. Сначала проверить, какие работают без Node.js (удалённые HTTP), а какие требуют `npx`.
5. Автопроверки (`Build.ps1 -Test`), GitHub Actions, первый релиз.
