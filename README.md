# Antigravity Toolkit

Набор улучшений для агента в Antigravity App: русские слэш-команды, пресеты правил и (позже) MCP-серверы.

> Статус: черновик. Установщика пока нет, команды ставятся вручную. Проверено на Antigravity App 2.26.

Отдельный проект от [Antigravity Russian](https://github.com/ZakitKH0000/antigravity-russian). Работает вместе с русификатором и анлокером региона и не меняет ни `app.asar`, ни Language Server.

## Команды

| Команда | Что делает |
| --- | --- |
| `/handoff` | Сохраняет итог чата в `.agents/handoff/latest.md`, чтобы продолжить в новом чате без потери контекста |
| `/resume` | Продолжает работу по сохранённому итогу |
| `/review` | Проверяет текущие изменения на ошибки |
| `/commit` | Готовит осмысленный коммит |
| `/fix` | Находит причину ошибки и исправляет её с проверкой |
| `/explain` | Объясняет устройство проекта или файла |

## Ручная установка

1. Скопируйте папки из `skills/` в `%USERPROFILE%\.gemini\config\skills\` (создайте папку, если её нет). Не заменяйте уже существующие папки с такими же именами.
2. Перезапустите Antigravity. Команды появятся в чате при вводе `/`.

Удаление — удалить эти папки. Наши папки помечены файлом `.antigravity-toolkit`.

## Правила для агента

Правила действуют во всех чатах без вызова команды.

| Файл | Когда действует | Что делает |
| --- | --- | --- |
| `antigravity-toolkit-context-economy.md` | всегда | Читать только нужное, сокращать вывод, вовремя предлагать `/handoff` |
| `antigravity-toolkit-confirm-destructive.md` | всегда | Спрашивать перед удалением, `git push --force`, публикацией, изменением системы и т. п. — даже при автоматическом выполнении команд |
| `antigravity-toolkit-code-style.md` | когда агент пишет код | Стиль окружающего кода, минимальные изменения, честная проверка |

Установка: скопируйте файлы из `rules/` в `%USERPROFILE%\.gemini\config\rules\` и перезапустите Antigravity. Удаление — удалить эти файлы. Правило языка из Antigravity Russian (`antigravity-russian.md`) лежит там же и не затрагивается.
