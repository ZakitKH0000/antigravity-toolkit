# Antigravity Toolkit

Улучшения для агента в Antigravity App: русские слэш-команды, правила поведения и MCP-серверы. Проверено на Antigravity App 2.26, Windows.

> **Агенту:** если пользователь просит установить, обновить или удалить эти улучшения — следуй [INSTALL-AGENT.md](INSTALL-AGENT.md).

## Установка в одно сообщение

Отправьте агенту Antigravity в любом чате:

```text
Установи улучшения из https://github.com/ZakitKH0000/antigravity-toolkit по инструкции INSTALL-AGENT.md
```

Агент сам скачает репозиторий, покажет, что можно поставить, спросит, что выбрать, установит и попросит перезапустить Antigravity. Так же можно попросить обновить («обнови Antigravity Toolkit») или удалить.

Отдельный проект от [Antigravity Russian](https://github.com/ZakitKH0000/antigravity-russian). Работает вместе с русификатором и анлокером региона и не меняет ни `app.asar`, ни Language Server.

## Команды

| Команда | Что делает |
| --- | --- |
| `/handoff` | Сохраняет итог чата в `.agents/handoff/latest.md`, чтобы продолжить в новом чате без потери контекста |
| `/resume` | Продолжает работу по сохранённому итогу |
| `/review` | Проверяет текущие изменения на ошибки |
| `/commit` | Готовит осмысленный коммит |
| `/fix` | Находит причину ошибки и исправляет её с проверкой |
| `/explain` | Объясняет устройство проекта или файла |

## Правила для агента

Правила действуют во всех чатах без вызова команды.

| Правило | Когда действует | Что делает |
| --- | --- | --- |
| `context-economy` | всегда | Читать только нужное, сокращать вывод, вовремя предлагать `/handoff` |
| `confirm-destructive` | всегда | Спрашивать перед удалением, `git push --force`, публикацией, изменением системы и т. п. — даже при автоматическом выполнении команд |
| `code-style` | когда агент пишет код | Стиль окружающего кода, минимальные изменения, честная проверка |
| `memory` | всегда (если подключён MCP `memory`) | Агент сам ищет в памяти факты о проекте и сам записывает предпочтения, решения и исправления; секреты не записывает |

## MCP-серверы

Каждый сервер добавляет описания своих инструментов в контекст, поэтому подключайте только нужные.

| Сервер | Что даёт | Как работает |
| --- | --- | --- |
| `context7` | Свежая документация библиотек и фреймворков | Удалённый, без ключа |
| `deepwiki` | Ответы по любому публичному репозиторию GitHub | Удалённый, без ключа |
| `microsoft-learn` | Документация Microsoft: C#, .NET, Windows, PowerShell | Удалённый, без ключа |
| `memory` | Память агента между чатами в `%USERPROFILE%\.gemini\antigravity-toolkit\memory.jsonl` | Локальный, нужен Node.js |

## Установка вручную

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -List
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -All
```

Другие варианты: `-Commands handoff,resume -Rules memory -Mcp context7`, `-Update`, `-Uninstall -All`. После изменений перезапустите Antigravity.

Что гарантирует установщик:
- меняет только свои файлы: папки команд с маркером `.antigravity-toolkit`, файлы правил с маркером `<!-- antigravity-toolkit:…-->`, записи MCP, указывающие на наши серверы;
- чужие файлы и серверы с такими же именами пропускает;
- перед изменением `mcp_config.json` сохраняет копию в `%USERPROFILE%\.gemini\antigravity-toolkit\backups\`; повреждённый файл не перезаписывает;
- при удалении не трогает файл памяти агента.

Проверки установщика: `powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-Install.ps1`.
