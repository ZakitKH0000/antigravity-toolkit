# Antigravity Toolkit

Набор улучшений для агента в Antigravity App: русские слэш-команды, пресеты правил и (позже) MCP-серверы — в виде одного штатного плагина Antigravity.

> Статус: черновик. Установщика пока нет, плагин ставится вручную.

Отдельный проект от [Antigravity Russian](https://github.com/ZakitKH0000/antigravity-russian). Работает вместе с русификатором и анлокером региона и не меняет ни `app.asar`, ни Language Server.

## Команды

| Команда | Что делает |
| --- | --- |
| `/handoff` | Сохраняет итог чата в `.agents/handoff/latest.md`, чтобы продолжить в новом чате без потери контекста |
| `/resume` | Продолжает работу по сохранённому итогу |
| `/review` | Проверяет текущие изменения на ошибки |
| `/commit` | Готовит осмысленный коммит |
| `/fix` | Находит причину ошибки и исправляет её с проверкой |
| `/explain` | Объясняет устройство проекта или файла |

## Ручная установка

1. Скопируйте папку `plugin/antigravity-toolkit` в `%USERPROFILE%\.gemini\config\plugins\`.
2. Перезапустите Antigravity. Плагин появится в настройках плагинов, команды — в чате через `/`.

Удаление — удалить эту папку или выключить плагин в настройках Antigravity.

## Пресеты правил

В `presets/rules/` лежат короткие правила (экономия контекста, подтверждение опасных действий, стиль кода). Чтобы включить, скопируйте нужные в `plugin/antigravity-toolkit/rules/AGENTS.md` перед установкой. Будущий установщик будет делать это галочками.
