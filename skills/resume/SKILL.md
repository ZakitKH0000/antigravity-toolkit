# Продолжение по сохранённому итогу

1. Прочитай `.agents/handoff/latest.md` в корне рабочей папки. Если файла нет — скажи об этом и предложи описать задачу заново.
2. Открой файлы из раздела «Важные файлы», нужные для первого шага из «Дальше». Не читай всё подряд — экономь контекст.
3. Сверь «Текущее состояние» с реальностью: `git status` и при необходимости короткая проверка. Если состояние расходится с записью — сообщи, что изменилось.
4. Кратко (3–5 строк) перескажи пользователю, где остановились и какой следующий шаг, и спроси, продолжать ли его.
